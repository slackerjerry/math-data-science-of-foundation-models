# Chapter 4 calculations

Run from the source package's `course/` directory with Python 3:

```bash
python3 chapter04/mean_distribution_example.py
python3 chapter04/finite_candidates_examples.py
```

The first program compares the scalar conditional mean, full probability readout and task risk in the four-value view. The second evaluates finite matching losses, the bounded-decision calculation and P7's partially retained-information example. These are exact finite-distribution calculations, not measured training outcomes. Their source contains worked answers, so attempt the corresponding problems before consulting it. Chapter 5 separately studies learned features.
