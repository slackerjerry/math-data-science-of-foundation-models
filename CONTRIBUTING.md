# Contributing

For an error report, identify the chapter, equation/problem or script, the release version, and a minimal reproducing command. State the expected and observed result, relevant assumptions, and Python/package versions.

Keep changes focused. Preserve the distinction between an exact calculation, a Monte Carlo check and a neural-network experiment. Do not replace a retained result with a newly trained value without also documenting the changed procedure and checking its references in the notes.

Run the relevant check suite in an isolated copy. Add a small check for a repaired dependency or interface when useful. Never commit access tokens, local environment folders or large unrequested datasets. Course credit and bonus decisions follow the syllabus, not this contribution file.
